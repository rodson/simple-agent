# 第 1 阶段数据模型：联网搜索

**日期**：2026-11-24 | **关联**：[spec.md](spec.md) / [plan.md](plan.md) / [research.md](research.md)

## 实体

### 网络检索结果（新增）

| 字段 | 类型 | 含义 |
|---|---|---|
| `kind` | 固定值 `web` | 与本地片段区分 |
| `title` | 字符串 | 结果标题，已去除标签与常见实体转义 |
| `url` | 字符串 | 可打开核验的真实网址（还原跳转后的地址） |
| `snippet` | 字符串 | 摘要，已去除标签与多余空白 |

- **校验规则**：`url` 必须以 `http` / `https` 开头；`title` 与 `snippet` 去空白后非空才纳入；
  按 `url` 去重；单次回答至多 5 条；解析异常时整批视为空结果。
- **生命周期**：仅在一次 `answerOnce` 调用内存在；不写入 Chroma、不落盘、不进入对话历史、
  不参与 `docs/` 摄入。

### 本地片段（既有，字段不变）

| 字段 | 类型 | 含义 |
|---|---|---|
| `source` | 字符串 | 文档文件名 |
| `chunk` | 数字 | 片段序号 |
| `text` | 字符串 | 片段正文 |
| `similarity` | 数字或空 | 余弦相似度 |

- 新增 `kind` 固定值 `local`（缺省时按 `local` 处理），其余字段与输出格式保持不变。

### 回答来源（联合集合）

- 一次回答的 `sources` 是「本地片段」与「网络检索结果」的联合数组，去重键为 `kind + 标识`
  （本地用 `source + chunk`，网络用 `url`）。
- 关系：一次回答 → 0..N 个本地片段 + 0..5 个网络结果；网络结果**不**关联任何文档或片段。
- 该集合同时供回答末尾的「参考来源」与交互模式 `/sources` 使用。

### 联网搜索配置

| 字段 | 默认值 | 类型 | 校验 |
|---|---|---|---|
| `WEB_SEARCH` | `false` | 布尔 | 复用 `src/config.js` 的 `booleanFlag`，非法值报错退出 |
| `WEB_SEARCH_ENDPOINT` | `https://html.duckduckgo.com/html/` | 字符串 | 构造请求时用 `new URL()` 校验，非法值按配置错误处理 |

- 启动时读取，运行期不变；交互模式不提供开关命令，避免会话中途改变隐私状态。
- 常量（非配置项）：超时 10 秒、单次结果上限 5 条、单次回答对外检索上限 1 次，
  均集中定义在 `src/websearch.js`。

### 对外检索词与检索计数

- **对外检索词**：由当前用户提问去掉首尾空白后得到；**不得**拼接本地片段、历史对话、
  系统提示词或模型生成的关键词。
- **检索计数**：每次 `answerOnce` 从 0 开始，成功发起一次对外请求后变为 1；达到 1 后
  后续 `search_web` 调用返回「已达上限」的工具错误，不再发请求。

## 状态流转

```text
回答开始 → 确定性本地检索
  ├─ 本地为空 + 联网关闭 → 短路返回「知识库中没有相关信息」
  ├─ 本地为空 + 联网开启 → 兜底联网检索（计数 0→1）
  │    ├─ 无网络结果 → 短路返回并提示联网未成功
  │    └─ 有网络结果 → 进入模型回答（仅网络来源）
  └─ 本地非空 → 进入模型回答
       └─ 模型可调用 search_web（计数未满时 0→1，结果并入来源）
模型回答结束 → 打印「参考来源」（有网络来源时加标签）→ 更新历史与 /sources 缓存
```

## 不涉及的持久化

- 不新增集合、表、文件或缓存；`chroma-data/` 的内容与结构不变。
- `docs/` 属于用户数据，本功能不读取以外的改写，也不把网络结果写回文档。
